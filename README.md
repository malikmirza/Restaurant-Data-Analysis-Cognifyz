# Restaurant Data Analysis using Python

## 📌 Project Overview
This project was completed as part of the **Data Analysis Internship at Cognifyz Technologies**.
The objective of this project is to analyze a real-world restaurant dataset and extract meaningful insights using Python.

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib

## 📊 Analysis Performed

### Level 1
- Top cuisines analysis
- City-wise restaurant distribution
- Price range distribution
- Online delivery analysis

### Level 2
- Ratings distribution and average votes
- Cuisine combination analysis
- Geographic analysis using latitude and longitude
- Restaurant chain analysis

### Level 3
- Sentiment analysis derived from ratings
- Votes vs ratings correlation
- Price range vs online delivery and table booking analysis

## 📈 Key Insights
- Certain cuisines and cities dominate the restaurant dataset
- Higher-rated restaurants generally receive more votes
- Higher-priced restaurants are more likely to offer online delivery and table booking
- Restaurants show geographic clustering in specific regions

## 🎯 Conclusion
This project demonstrates end-to-end data analysis skills including data cleaning, EDA, visualization, and insight generation using Python.
